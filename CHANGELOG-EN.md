The achievements update.

## Features

- added a system of eight achievements based on created exercises, measurements, completed workouts, lifted weight, and consistency,
- added a widget showing the three most recently unlocked achievements and a full list screen with descriptions and unlock status,
- unlocking an achievement now displays a temporary in-app message at the top and an optional system notification,
- added separate notification settings for achievement alerts and reminders sent after five days without a completed workout,
- added alphabetical exercise sorting with favorites always remaining at the top,
- exercises can now be marked as favorites so they remain at the top regardless of sorting,
- added new theme - "Energy".

## Fixes

- added safe fallbacks for muscle-group and measurement-category lists when a newly added language has no domain-label variant, preventing crashes when expanding or creating exercises,
- unified dropdown widths and positioning in the exercise creator, improving time-value selection,
- clicking a bottom-navigation tab now always opens its section's main screen,
- leaving an active workout with bottom navigation now requires confirmation in the modal.
